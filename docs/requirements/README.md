直播增强开关的要求是 **默认关闭**，覆盖新布局和互动面板，与点播并发 CDN、直播 CDN 选择及将来的直播网络加速分别控制。关闭后仍保留现有直播播放、弹幕与 SC 展示。开启界面不会自动送礼、入团、点亮灯牌、购买或续订；勋章佩戴与灯牌点亮也是不同操作。以上为本版和后续实现共同的验收条件。

P0 的真实海外网络 A/B 性能、macOS GUI 画面/声音/seek 和移动端行为尚未验证。[验收记录](../harness/validation.md)按实际范围列出构建、回环和原生播放结果；不能把它们当作这些平台或性能结论。
