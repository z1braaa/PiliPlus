## 官方直播证据等级

1. **入口可见**：公开页面出现模块或按钮，只支持“存在入口”。
2. **静态脚本线索**：前端资源引用了标识、事件或端点，只支持“该版本资源含此引用”。manifest 中所有 `verified_api_contract` 均为 `false`。
3. **只读响应已验证**：用明确账号/房间条件验证请求和响应，记录字段、错误及可能的版本差异，才能描述实际只读行为。
4. **授权操作已验证**：在明确许可和可控账号下完成写操作，核对服务端最终状态及超时/重复提交结果，才能声明完整交互流程可用。
5. **跨平台体验已验收**：对照官方网页与当前 PC 版本，在目标平台逐项记录入口、布局、权限、状态同步和失败行为，才能讨论“等量”。

较高一级不能由较低一级推断。尤其是勋章佩戴与灯牌点亮为不同流程；静态资源显示点亮关联送礼路径，但是否免费、价格、权限和最终结果均须看当前服务端配置。开启增强界面不应触发这些操作。

## 复核与记录

- 官方资源 manifest 保存 URL、SHA-256、字符和字节偏移。若旧 URL 无法重取或摘要变化，应保存新版本的来源与差异；不能用旧偏移指向不同内容。不要把会话凭据、签名媒体 URL、礼物图片或整套压缩脚本提交到仓库。
- 对接口分别记录请求方法、必要输入、账号/房间前置条件、响应示例的脱敏摘要、错误码、限流或灰度表现、复核日期。未调用过的端点继续标“候选”。
- 官方 Windows PC 客户端尚未运行核对；[直播路线图](../requirements/03-live-ui-roadmap.md)中的“等量”是待建立的逐项基准，不能先宣称完成。
- 对用户报告的“起播慢、开始后改善”，当前 V2 结构提供一种解释。只有阶段耗时与受控对照才能确认主因和收益；不要把海外 CDN 未缓存作为已证实原因。
