# 本版之后的未落地与待验证清单

更新：2026-09-28。对应官方 2.1.5 + CDN P0 + 默认关闭直播 L1/L2 的工作分支；交付包为 `2.1.5-CDN-P0-LIVE-L2+5424`，源码 `ae1715ee…`，最低 macOS 13；摘要以[构建记录](results/live-macos-build-5424.json)为准。本表区分源码已实现但未在线验证，与仍没有实现的功能。

## 本版已写入源码

- 独立直播增强开关，缺省/非法配置关闭；宽屏侧栏，窄窗/全屏互动抽屉；礼物、背包、粉丝团/灯牌和当前主播勋章界面。
- SC 去重、删除优先、集中到期和常驻历史；有界消息重连、认证/心跳超时与旧会话隔离。
- 普通金/银瓜子与背包投喂；入团/点亮使用当前服务端指定礼物；佩戴/摘下分别操作。确认绑定账号/对象/价格/数量，过期或关闭后不再提交；写请求不自动重试。
- 提交前持久化未决状态，重开/重启不重发；匹配回执才确认送礼；入团/灯牌还需最新目标状态确认。

这些功能的模拟协议/状态机测试通过，只支持客户端实现正确性；实际账号读写和费用结果尚未验证，不能宣称与官方网页/PC 等量。
