# 验收矩阵与结果记录

更新日期：2026-09-25。P0 `NET-02`～`NET-07` 已有工作分支代码；确定性回环、macOS Release 构建和原生 mpv 实媒体冒烟验证的结果记录如下。`NET-01` 的脱敏阶段日志已实现，但 media_kit 当前路径尚不能可靠给出每源首帧与首音频时间。既有 V2 测试与原生验证结果在[历史 V2 文档](../parallel-cdn-playback-v2.md)，不能当作 P0 新需求的测试结果。

## 点播网络：从正确性到真实收益

| 层次 | 最少场景 | 判定与记录 |
| --- | --- | --- |
| 阶段诊断（NET-01） | 冷启动、热启动；热门/冷门视频；关闭与开启并发；首播及 seek | 分别记录 URL 就绪、候选准备、排队/额度获批、首个上游字节、代理首字节；按轨道、会话和请求关联且脱敏。首帧/首音频暂记不可用，不以 `playing` 或代理首包代替；稳定播放时间待验证 |
| 协议与资源身份（NET-02～07） | HEAD/Range、不同块大小、两个以上 CDN、失败/重定向/内容不一致、断开 | 字节序、范围和长度正确；坏源不拼入；原始来源回退合规；取消后无旧任务泄漏或不受控下载 |
| 恢复（NET-08～12） | 中途断线、403/签名过期、长暂停、连续 seek、切画质/音轨、账号切换 | 重试仅补缺失字节，不污染新会话；诊断中的请求和流量与实际行为对应 |
| 可选策略（NET-13～16） | 单项独立开关，固定手动配置作对照；低速/限流/高延迟网络 | 同时报告起播、卡顿、重复字节、峰值内存与连接数；无净收益则维持默认关闭 |
| 用户网络 A/B | 同设备、网络、账号、视频/分 P、画质/编码；交替开/关顺序 | 起播时间、固定时段卡顿次数和时长、seek 恢复、有效/重复流量、峰值内存；每组保留原始单次数据 |

[起播计划](../requirements/02-startup-optimization-plan.md)提出 P0 的**候选目标**：问题样本起播中位数相对 V2 缩短至少 30%，健康直连样本起播 P95 增量不超过 500 ms。每组 5 次只用于初筛；正式 P95 的样本量、网络分层及波动处理须先确定，不能用 5 次结果宣称达标。海外 CDN 是否未缓存需另有直接或间接证据，不能由慢起播单独推定。

探索性同机同网、同一匿名 DASH 样本按 P0 → V2 → P0 顺序做了三次静音 headless 播放；mpv `file_loaded` 分别约 19.0、20.2、18.8 秒，达到播放位置 2 秒分别约 21.1、22.3、20.9 秒。两版均按地区策略生成 16 个大陆候选与 2 个其他候选，实际命中节点未记录。另一匿名样本按 P0 → 直连 → P0 顺序的 `file_loaded` 约 4.16、0.14、3.92 秒，说明该样本代理有明显额外等待。这些样本既没有达到用户目标网络 A/B 的控制条件与数量，也没有首帧/首音频事件；它们只能提示 P0 未见相对 V2 的明显回归，**不能证明 30% 起播收益或排除偶发慢载入**。完整签名 URL 未保存。

最终提交、安装包和 SHA-256 在随包记录中对应；其余未验证项维持原状。P1/P2 与直播界面仍在规划中，各自验收另行执行。

## 直播界面与交互

| 组合 | 应核对的行为 | 对应需求 |
| --- | --- | --- |
| 首装、旧配置缺失、非法存储值、重置默认 | 增强关闭，原布局和基础播放/弹幕/SC 展示可用；没有额外面板任务 | LIVE-UI-01/02 |
| 手动开启、重启、合法备份恢复 | 显式偏好保留；未适配模块不可冒充可用 | LIVE-UI-03/06 |
| 正在播放时反复开关、窗口/全屏变化 | 不重建播放器、不重拉流；音量、画质、弹幕连接稳定；无重复监听 | LIVE-UI-05 |
| 与点播并发、直播 CDN、未来直播加速的所有开关组合 | 各设置独立，直播增强不改变传输路线或清晰度 | LIVE-UI-04 |
| 游客/登录、切账号/房间、房间不支持、断线重连 | 权限与模块状态及时更新；旧请求不会覆盖新房间；基础消息恢复 | LIVE-UI-03/08、LIVE-FN-05 |
| 关闭未提交面板或已提交但结果未知的操作 | 未提交的动作不发出；结果未知只读核对，不盲目重发或重复消费 | LIVE-UI-07、LIVE-FN-01～04 |
| 礼物、粉丝团、SC、大航海、PK 等逐项官方基准 | 当前网页与 PC 的入口、账号条件、发送/审核/回执、失败及可用平台逐项对照 | LIVE-FN-01～06 |

付费或账号状态改变的验收必须使用有权限的受控账号和明确许可，显示服务端返回的当前价格/权益，并核对最终状态。静态脚本出现端点、打开外部官网页面或本地弹出“成功”，均不足以判定应用内流程完成。经验证的官方内嵌 H5 可标记“混合实现”，与原生和外部跳转分别记录。
