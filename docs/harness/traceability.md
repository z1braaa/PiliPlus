# 需求追踪表

更新日期：2026-09-28。本表把需求 ID、阶段、最小验收和状态连接起来；具体设计以[起播需求](../requirements/02-startup-optimization-plan.md)及[直播路线图](../requirements/03-live-ui-roadmap.md)为准。[验收矩阵](validation.md)给出组合场景。P0 工作分支已有代码，确定性回环验证通过；用户已提供初筛反馈，严格海外网络 A/B、macOS GUI 和移动端验收仍未完成。

状态“回环通过”只表示实现已写入工作分支并通过本机确定性协议测试，不表示真实网络性能目标达标；“规划中”表示仍待交付，“待核实”表示实施前还缺官方接口或平台基准。已实现 V2 的能力见[单独记录](../parallel-cdn-playback-v2.md)，不因名称相似而将新需求标完成。
